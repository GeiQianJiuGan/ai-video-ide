# 镜头关系画布与提示词构筑

进入单个 Shot 后默认打开「镜头画布」。原来的角色、道具、上游依赖、配音、导入版本和生成参数保留在「详细检查 / 参数」中。

## 画布操作

- 中心显示当前采用的视频；未生成时显示首帧或空画面。
- 首帧固定在左侧，尾帧固定在右侧，标注起止时刻。自动继承的帧带锁定提示。
- 工程素材可拖到空白画布作为参考，也可拖到首尾帧卡片指定起止画面；首尾帧只接受图片。
- 拖动素材卡片标题调整位置，拖动画布背景平移；工具栏提供缩放、适应画布和整理。布局按工程和 Shot 保存在本机浏览器中。
- 点击素材查看描述、插入引用或断开参考连接。移除连接不会删除素材文件。未采用素材和容量问题仍可查看。
- 右侧可预览历史版本、采用版本、查看该版冻结的提示词和图片映射。历史预览时周围素材与底部编辑器仍属于当前草稿，界面明确说明这一点。

## 手动构筑提示词

输入 `@` 打开素材候选列表，支持按名称过滤以及上下键、回车、Escape。也可以点击素材卡片上的「@ 引用」或编辑器下方的快捷引用按钮。

引用显示为可点击标签；点击可定位画布，悬停可预览素材。复制提示词时保留稳定素材链接，粘贴后恢复标签。保存、重载或素材重新排序不会把链接改指向其他图片。

底部提供六个可自由切换的阶段：素材与主体、起始画面、动作发展、运镜与收尾、声音、检查。模板需要补齐具体动作与声音；尾帧模板会引用当前尾帧并带上实际时长。

「插入 H3 结构」根据素材形态提供基础三字段或全参考六字段的骨架；基础关键帧模式附带起止时间对齐句。这个操作不调用 LLM，也不自动翻译中文或补齐创作内容。检查阶段会提醒尚未替换的占位内容。

编辑后自动保存，也可按 Ctrl / Command + Enter 保存；生成、刷新和通过应用内路由离开前会等待保存。保存失败会保留草稿并显示后端错误。清空 Shot 提示词恢复幕级继承。

## 引用与生成的一致性

正文中的链接使用 `@[显示别名](asset:稳定素材ID)`，帧槽位使用 `@[首帧](frame:first_frame)` 和 `@[尾帧](frame:last_frame)`。界面别名与模型的 `<Picture N>` 是不同编号。

入队前验证素材是否存在于该 Shot 的有效上下文中，以及是否超出工作流容量；适配器在得到实际输入顺序后再解析链接。参考素材移到首尾帧槽位时，原有资产链接仍能解析。同一图片同时用于首尾帧时，图册去重但保留两个帧角色。

手动编辑明确清除该 Shot 旧的导演意图，避免生成时被旧意图覆盖。原始创作提示词、实际发送提示词及图片映射保存在生成版本记录中。编辑当前草稿不会修改已有版本。

「版本提交记录」展示已经提交的冻结记录。新草稿最终编号由实际工作流确定，不在前端猜测。输入模式提示描述当前素材形态，实际支持的模式、音视频参考类型和容量由所选工作流决定。

## 验证

后端回归覆盖实际图片顺序与显示别名不一致、素材缺失 / 超容量、同图首尾帧、参考转为帧、仅首尾帧工作流、无提示词入口、不可提交的音频引用、REST 图册、完整 H3 结构和手动编辑覆盖旧导演意图。

浏览器验收使用独立工程，验证中心视频与历史版本预览、素材引用候选、键盘选择、连续输入、尾帧模板、自动保存后重载、复制粘贴链接、移除尾帧后的失效提示以及恢复引用。
