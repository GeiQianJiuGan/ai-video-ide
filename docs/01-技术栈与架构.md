# 技术栈与架构设计

> AI Video Studio（代号 xunjie_video_ide）——桌面端优先的 AI 原生长视频制作工作台
> 定位：**AI = 素材生产器 / System = 视频工程与编排器 / Human = 导演**

---

## 1. 选型总览

| 层 | 选型 | 版本基线 | 理由 |
|---|---|---|---|
| 桌面壳 | Tauri 2 | 2.x | 体积小、原生文件系统权限模型、可用 sidecar 托管 Python 进程 |
| 前端框架 | Vue 3（Composition API） | 3.5+ | 指定技术栈；`defineModel` / 泛型组件对复杂编辑器组件友好 |
| 语言 | **TypeScript（strict）** | 5.6+ | 本系统的核心复杂度在数据模型（Character→Appearance→Shot→Context→Version→Clip），弱类型会直接失控。**不建议用 JS** |
| 构建 | Vite | 6.x | 指定技术栈 |
| 状态 | Pinia + `pinia-plugin-persistedstate` | 2.x | 指定技术栈；按 feature 切 store |
| 路由 | Vue Router 4 | 4.x | 多工作区页面 |
| 样式 | Tailwind CSS v4 + CSS 变量 Design Token | 4.x | 高信息密度界面靠 token 统一密度/层级，不靠组件库 |
| 无头组件 | reka-ui（Radix Vue 后继） | 2.x | 只取 Dialog/Popover/Menu/Tooltip/Splitter 等行为，外观全自研 |
| 图标 | Lucide | — | 线性图标，契合专业软件观感 |
| 虚拟滚动 | `@tanstack/vue-virtual` | — | Storyboard 数百 Shot 卡片、Asset 库网格 |
| Timeline 渲染 | **自研 Canvas 2D 渲染层**（非 DOM） | — | 多轨 × 数百 Clip 用 DOM 必然掉帧；Canvas 可控层级、缩放、命中测试 |
| 音频波形 | FFmpeg 预计算 peaks（`.peaks` 二进制）+ Canvas 绘制 | — | 避免前端解码整段音频 |
| 后端 | Python 3.11+ / FastAPI / Uvicorn | FastAPI 0.115+ | 指定技术栈；与 ComfyUI 生态同语言 |
| 校验/DTO | Pydantic v2 | 2.9+ | 生成 OpenAPI，前端类型自动同步 |
| ORM | SQLAlchemy 2.0（async）+ Alembic | 2.0+ | 数据模型演进频繁，必须有迁移 |
| 数据库 | SQLite（WAL 模式） | 3.4x | 阶段一单机；schema 保持可迁移到 Postgres |
| 实时通道 | 原生 WebSocket + 事件总线 | — | 队列进度、Job 状态、GPU 状态推送 |
| 任务队列 | **自研 asyncio 调度器 + SQLite 持久化 + DAG 依赖** | — | 阶段一不引入 Redis/Celery，避免用户装外部服务 |
| 视频生成 | ComfyUI HTTP API + `/ws` 进度 | — | 指定技术栈 |
| 媒体处理 | FFmpeg / FFprobe（subprocess 封装） | 6.x+ | 抽帧、尾帧、代理转码、拼接、导出、波形 |
| LLM | Provider 抽象：OpenAI 兼容 / Anthropic / Ollama / 无 | — | **LLM 必须可完全关闭**（Manual 模式） |
| 图像生成 | 走同一条 Workflow Adapter（Character Sheet 也是 ComfyUI workflow） | — | 不为图像单开一套通路 |
| 日志 | structlog（后端）+ 环形缓冲日志面板（前端） | — | 生成失败必须可追溯，绝不静默 |
| 测试 | pytest + pytest-asyncio / Vitest / Playwright（可选） | — | Context Resolver、Workflow Adapter、Scheduler 必须有单测 |
| 打包 | PyInstaller（后端 sidecar）+ Tauri bundler | — | 用户不需要自己装 Python |

### 明确不做的选择（及原因）

- **不用 Electron**：包体与内存开销对同时跑 ComfyUI 的机器不友好。
- **不用 Celery / Redis / RabbitMQ**（阶段一）：单机个人使用，多一个常驻服务就多一个失败点。调度器接口设计成可替换。
- **不用现成时间线库**（如 vue-timeline 类）：需要 Clip↔Version 替换、Scene 分组、AI 状态叠加，现成库都要魔改。
- **不用 GraphQL**：REST + WebSocket 足够，且 OpenAPI 能直接生成前端类型。
- **不在阶段一做 WebGPU 合成预览**：预览用「代理视频 + 单轨播放 + 跨轨切换」，合成质量交给导出时的 FFmpeg。

## 2. 进程与运行架构

```text
┌─────────────────────────────────────────────────────────┐
│ Tauri Shell (Rust)                                      │
│  · 窗口 / 菜单 / 文件对话框 / 本地路径权限                  │
│  · sidecar 生命周期管理（启动/健康检查/优雅退出）            │
│  ├── WebView: Vue 3 UI  ──HTTP/WS──┐                    │
│  └── sidecar: Python FastAPI  ◄─────┘ 127.0.0.1:<随机端口> │
└─────────────────────────────────────────────────────────┘
                          │
              ┌───────────┴───────────┐
              │                       │
        ComfyUI (外部)            FFmpeg (捆绑二进制)
        HTTP + /ws                subprocess
              │
   Wan / Hunyuan / LTX / 用户自定义 Workflow
```

要点：

1. 端口随机分配，启动时由 Tauri 写入前端 `window.__AIVS_ENDPOINT__`；**不监听 0.0.0.0**。
2. sidecar 与前端之间用一次性 token 做握手，防止本机其他程序访问工程数据。
3. ComfyUI 地址由用户在 Settings 配置（默认 `http://127.0.0.1:8188`），支持连通性探测与 Capability 探测。
4. FFmpeg 优先用捆绑二进制，其次回退到系统 PATH，两者都没有则在 Settings 明确报错。

## 3. 生成链路（绝不让业务层绑定具体模型）

```text
UI 发起 / Queue 触发
        ↓
GenerationRequest（与模型无关的中立请求）
        ↓
Context Resolver      ← Character/Appearance/Location/Prop/PrevFrame DB
        ↓  产出 ResolvedContext（含具体资产路径与 crop 区域）
Workflow Resolver     ← Workflow Registry + Capability 匹配 + 打分
        ↓  选出 Workflow，或抛 MissingCapability 明确错误
Workflow Adapter      ← Node 绑定表（prompt/image/video/lora/seed/output）
        ↓  产出 ComfyUI Prompt Graph（纯 JSON）
ComfyUI Client        → POST /prompt，订阅 /ws 进度
        ↓
Output Collector      → 落盘 + FFprobe + 抽尾帧 + 缩略图 + 代理
        ↓
GenerationVersion（永不覆盖）
```

**关键约束**

- 业务代码里不允许出现 `if model == "wan"` 这类分支；差异全部下沉到 Adapter。
- `T2V / I2V / R2V / Extend / V2V / StartEnd` 在内部只是 `GenerationRequest` 的输入组合结果（Generation Context），不是硬编码枚举分支；`mode` 字段只用于「用户强制」与「Resolver 输出解释」。
- Capability 不匹配时**必须**返回结构化错误（缺什么能力、建议切换到哪些 Workflow），不允许降级静默执行。

## 4. 后端模块边界

```text
backend/app/
├── main.py                    # FastAPI 装配、生命周期、sidecar 握手
├── api/                       # 只做 HTTP/WS 适配，无业务逻辑
│   ├── projects.py  characters.py  locations.py  props.py
│   ├── story.py     scenes.py      shots.py
│   ├── generation.py  queue.py     workflows.py
│   ├── assets.py    timeline.py    export.py    settings.py
│   └── ws.py                  # 单一 WS 端点 + 频道订阅
├── domain/                    # 纯实体 / 值对象 / 枚举，零 IO 依赖
├── services/                  # 用例编排（事务边界在这里）
├── context/                   # ★ Context Resolver + Crop 策略 + 连续性规则
├── prompt/                    # ★ Prompt Compiler（分层拼装 + 模板）
├── generation/
│   ├── request.py             # GenerationRequest / ResolvedContext
│   ├── resolver.py            # Workflow Resolver（capability 匹配打分）
│   ├── adapters/              # base.py + wan.py + generic_binding.py
│   ├── comfy/                 # client.py（HTTP+WS）/ graph.py / probe.py
│   ├── scheduler.py           # ★ DAG + 优先级 + worker 池 + 断点恢复
│   └── collector.py           # 产物落盘 / 元数据回填
├── media/                     # ffmpeg.py ffprobe.py frames.py proxy.py peaks.py
├── ai/                        # llm/（provider 抽象）+ director/（剧本分析）
├── persistence/               # models.py repositories/ migrations/
├── events/                    # 事件总线 → WS 广播
└── core/                      # config / errors / logging / paths / ids
```

依赖方向单向：`api → services → (context|prompt|generation|media|ai) → persistence`。
`domain` 不依赖任何上层；`context` 不允许直接调 ComfyUI。

## 5. 前端模块边界

```text
frontend/src/
├── app/                # 入口、路由、主题 token、全局快捷键
├── shared/
│   ├── api/            # 由 OpenAPI 生成的 client + WS 客户端
│   ├── ui/             # 自研基础组件（Panel/Split/Card/StatusDot/Field...）
│   ├── media/          # VideoPlayer / FrameStrip / ThumbGrid
│   └── lib/            # 时间码、时长格式、拖拽、命令总线
├── features/
│   ├── project/        # Dashboard、项目设置
│   ├── character/      # Character Studio、Appearance 树、Sheet 查看/裁切
│   ├── location/       props/
│   ├── story/          # 剧本编辑 + AI Director 面板 + 三种模式切换
│   ├── storyboard/     # Scene 泳道 + Shot 卡片网格 + 批量生成
│   ├── shot/           # Shot Editor：Prompt / Cast / Context Inspector / Versions
│   ├── generation/     # Queue 面板、Job 详情、错误诊断
│   ├── timeline/       # ★ Canvas 渲染器 + 编辑命令 + 撤销栈
│   ├── assets/         # Asset Library
│   ├── workflows/      # Workflow Manager + Node 绑定编辑器（高级）
│   └── settings/
└── stores/             # 每个 feature 一个 store，禁止跨 store 直接改 state
```

- **撤销/重做**：Timeline 与 Storyboard 用命令模式（`Command{do,undo}`）本地栈；资产类改动走服务端，不进撤销栈（改为版本化）。
- **乐观更新**：仅用于纯 UI 状态（选区、折叠）；涉及生成与版本的操作一律等服务端确认。

## 7. 关键技术风险与对策

| 风险 | 对策 |
|---|---|
| 长视频角色一致性漂移 | Character Sheet + Appearance 继承 + Previous Last Frame 强制注入；每个 Shot 记录 Character State（existing/entering/background）决定引用策略 |
| ComfyUI Workflow 千差万别 | Capability 声明 + Node 绑定表（用户手动映射一次）+ 导入时静态校验；不匹配即报错 |
| 生成任务长、易中断 | Job 状态全量持久化，重启后可恢复；ComfyUI `prompt_id` 落库以便重连认领结果 |
| 多轨预览性能 | 全部素材生成 720p 代理（密集关键帧）；预览播放代理，导出用原片 |
| SQLite 并发写 | WAL + 单写入串行化（服务层 write lock），读走独立 session |
| 磁盘暴涨（版本永不删） | 版本保留策略提示 + `cache/` 可清理 + 手动归档；默认不自动删除 |
| Schema 频繁变更 | Alembic 强制迁移 + `project.aivs.json` 记录 schema 版本，打开旧工程自动升级 |

## 8. 阶段一交付边界

**做**：Project / Character / Appearance / Character Sheet / Location / Story / Scene / Shot / Context Resolver / Prompt Compiler / Workflow Adapter / ComfyUI 接入 / Generation Queue（含 DAG）/ Generation Version / Timeline 基础编辑 / 基础导出。

**不做**：Props 深度用法、导入视频 AI 重制（V2V 全链路）、Effects 全家桶、音频混音、自动字幕、AI 转场推荐、云端 GPU、多人协作。这些在文档中保留接口位，不实现。
